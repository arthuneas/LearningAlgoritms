## Sobre o Repositório

Este espaço documenta o aprendizado prático de lógica de programação e a resolução de problemas computacionais ao longo do meu primeiro semestre na Universidade de Brasília (UnB). O objetivo é servir como um portfólio acadêmico inicial e um histórico de evolução na escrita de código. 

Todo o material aqui presente foi desenvolvido exclusivamente em linguagem C.

## Tópicos Abordados

O repositório está organizado de acordo com a progressão da ementa da disciplina, cobrindo os seguintes conceitos:

* **Lógica de programação** e entrada/saída de dados
* **Estruturas de controle de fluxo** (if, else, switch)
* **Estruturas de repetição** (while, do-while, for)
* **Estruturas de dados estáticas** (Vetores, Matrizes e Strings)
* **Modularização** (Funções e Procedimentos)

## Tecnologias

* Linguagem C
* Compilador GCC
